## Python-Datei mit virtuellem Environment starten
Mit dem Skript `run_with_venv.sh` kannst du eine (auch später hinzugefügte) Python-Datei starten. Falls noch kein virtuelles Environment existiert, wird automatisch `.venv` erstellt.

```bash
./run_with_venv.sh pfad/zu/deiner_datei.py
```
